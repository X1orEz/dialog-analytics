# Статистический отчёт

## Данные

- 200 клиентов, 800 диалогов, 1923 сообщений.
- Источник: синтетические данные (`src/generate_data.py`).
- Зависимости в данных: длительность зависит от канала и сегмента; статус — от канала, сегмента и длительности.

## A/B: длительность диалога chat vs email

- chat: n = 489, mean = 25.9 мин
- email: n = 239, mean = 46.3 мин
- t-тест Уэлча: t = -22.225, p < 0.001
- **Вывод:** различие статистически значимо (α = 0.05). Email-диалоги существенно длиннее.

## Chi-square: статус vs канал

- χ² = 48.434, p < 0.001
- **Вывод:** различие статистически значимо (α = 0.05). Статус зависит от канала.

## Bootstrap 95% CI для средней длительности chat

- Средняя: 25.9 мин
- 95% ДИ: [24.9, 26.7]

## Модель: предсказание escalated

Задача: предсказать, будет ли диалог эскалирован, по признакам:

- канал (`chat`, `email`, `phone`),
- сегмент клиента (`new`, `regular`, `vip`),
- длительность диалога (минуты).

Модель: логистическая регрессия, `class_weight="balanced"`.

Метрики на тестовой выборке (25%):

- ROC-AUC = 0.776
- PR-AUC = 0.413
- accuracy = 0.690
- precision = 0.325
- recall = 0.714
- f1-score = 0.446

**Вывод:** модель уверенно отличает escalated от не-escalated. PR-AUC существенно выше базовой доли положительного класса (~0.14), что говорит о наличии сигнала.

## Ограничения

- Данные синтетические — метрики отражают закономерности, заложенные в генератор, а не реальные бизнес-процессы.
- В реальных данных зависимость может быть слабее; ROC-AUC 0.776 — оптимистичная оценка.
- Признаки не включают текст диалога; в следующем шаге планируется LLM-разметка для обогащения.
